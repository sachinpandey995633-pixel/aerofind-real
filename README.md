# AeroFind Enterprise — Imagine Cup Project
AI-Assisted Aviation Baggage Recovery & IATA 753 Middleware

## Deploy to Vercel
1. Import GitHub repository into vercel.com
2. Framework: Vite
3. Build Command: npm run build
4. Output Directory: dist

## Deploy to Azure Static Web Apps
1. Azure Portal -> Create Static Web App
2. Connect GitHub Repository
3. App location: /
4. Output location: dist
5. Click Review + Create
